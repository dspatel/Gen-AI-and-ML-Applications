HOW_IT_WORKS — Rolling 30-minute Range Breakout Monitor
=======================================================

Goal
----
You wanted a rolling Opening Range style system:
- Build a 30-minute range.
- When that range breaks, send a notification (optional email) and log the breakout candle.
- Then redefine the range using the next 30 minutes of data after the breakout.
- Repeat all day.
- Do NOT track target hits/breaks (targets are informational only).

Data source
-----------
tvDatafeed pulls OHLCV candles from TradingView.
Required data per candle:
- time, open, high, low, close, volume

Core logic (state machine per symbol)
-------------------------------------
Each symbol is always in exactly one of these states:

1) BUILD_RANGE
   - Collect bars_needed candles.
   - bars_needed = ceil(OR_MINUTES / candle_interval_minutes)
     Example: OR_MINUTES=30 and 15m candles => 2 candles.
   - RangeHigh = max(high) across those candles.
   - RangeLow  = min(low)  across those candles.
   - When range completes:
       - compute targets (UpT1..UpTn and DnT1..DnTn)
       - log RANGE_READY row to Excel

2) WAIT_BREAKOUT
   - For each newly closed candle:
       breakout UP  if previous_ref <= RangeHigh AND current_ref > RangeHigh
       breakout DOWN if previous_ref >= RangeLow  AND current_ref < RangeLow
   - ref depends on BREAKOUT_REF:
       "close"   (recommended): uses candle close (confirmed after close)
       "highlow" (noisier): uses candle high/low
   - When breakout occurs:
       - log BREAKOUT row to Excel (includes candle close and indicators)
       - optional email is sent (BREAKOUT only)
       - reset to BUILD_RANGE to start the next 30-minute range window

Why bar-close guard matters
---------------------------
The script polls every POLL_SECONDS, but it only processes a candle when the
latest candle timestamp changes. This ensures you get exactly one evaluation per
closed candle, and prevents duplicate alerts/log rows.

Targets (informational only)
----------------------------
Targets are calculated when the range is created (RANGE_READY) and included
again in the BREAKOUT log/email for context.

Definitions:
- W = RangeHigh - RangeLow
- step = W * TARGET_PCT
- Optional ATR floor:
    step = max(step, ATR_FLOOR_MULT * ATR14)

Targets:
- UpT1..UpTn = RangeHigh + k*step
- DnT1..DnTn = RangeLow  - k*step

Also logged explicitly:
- next_high_target = UpT1
- next_low_target  = DnT1

Indicators logged (at RANGE_READY and BREAKOUT candle)
------------------------------------------------------
- EMA20, EMA50, EMA200
- ATR14 (Wilder ATR)
- RSI14
- VolSMA20

Excel output
------------
File: rolling_range_breakouts.xlsx
Sheet: events

Rows:
- RANGE_READY: includes RangeHigh/RangeLow and next_high_target/next_low_target + targets.
- BREAKOUT: includes direction, breakout_ref, candle OHLCV, close, and indicators.

Email (optional, Outlook)
-------------------------
To enable:
- set SEND_EMAIL_ALERTS = True
- fill EMAIL_CFG with your Outlook username/password (or app password)

SMTP defaults used:
- smtp.office365.com:587 with STARTTLS

Key places to debug (IDE breakpoints)
-------------------------------------
- fetch_with_exchange_fallback(): confirm data is being returned and exchange used
- evaluate_rolling_range(): confirm state transitions and breakout logic
- append_excel_row(): confirm Excel writes

Common tweaks
-------------
- Change interval: CANDLE_INTERVAL
- Change range window: OR_MINUTES
- Close-confirmed breakouts: BREAKOUT_REF="close"  (recommended)
- Faster/noisier breakouts: BREAKOUT_REF="highlow"
- Adjust target step: TARGET_PCT, ATR_FLOOR_MULT, USE_ATR_FLOOR
- Add symbols/exchanges: symbols.json


Toggles you asked for
---------------------
In monitor_rolling_orb.py you can control what gets written / notified:

Excel logging:
- LOG_RANGE_READY_TO_EXCEL = True/False
- LOG_BREAKOUT_TO_EXCEL = True/False (normally keep True)

Email:
- SEND_EMAIL_ALERTS = True/False   (master switch)
- EMAIL_ON_BREAKOUT = True/False   (only used when SEND_EMAIL_ALERTS=True)


End-of-day stop + daily snapshot
--------------------------------
If EXIT_AT_MARKET_CLOSE=True and MARKET_HOURS_ONLY=True, the script exits at market close, prints a snapshot, and (optionally) appends to Excel sheet 'daily_summary'.

After-hours testing
-------------------
Set TEST_MODE=True to replay the last TEST_BARS_TO_REPLAY historical bars quickly (no waiting) and generate logs after-hours.


Keeping test logs separate
--------------------------
Set SEPARATE_TEST_LOGS=True (default). When TEST_MODE=True, the script writes to a brand-new Excel file named like rolling_range_breakouts_TEST_YYYYMMDD_HHMMSS.xlsx so it never mixes with your daytime workbook.
