# Notification format

Emoji/labels are tied to metrics.

Direction:
- 🔺 UP, 🔻 DOWN

Mode:
- 🟢 LIVE, 🟣 REPLAY

RR phase:
- 🧊 pre-OR RR (include_today_or=0)
- 🔥 post-OR RR (include_today_or=1)

Setup:
- 🧩 ORs clustered, 🌀 ORs shifting, 🧷 ORs mixed
- 🧊 tight RR, ⚖️ balanced RR, 🔥 stretched RR
- 🟢 up-lean, 🔴 down-lean, 🟡 balanced bias

Quality:
- ✅ clean break, 🟨 moderate, ⚠️ weak
- 🧱 tight wick, 🪵 some wick, 🪶 wicky
- 💪 strong body, 🙂 ok, 🫥 thin body
